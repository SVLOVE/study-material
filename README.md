# GovPrep
GovPrep is a phase-based, incremental government exam preparation platform.

## Phase 1 Completed
- Initial Flutter project setup
- Material 3 configured
- Riverpod configured for State Management
- GoRouter configured for Routing
- Folder structure prepared for feature-driven architecture
- Environment variables configured via dotenv

## Running the App
1. Add your environment variables in `.env`
2. Run `flutter pub get`
3. Run `flutter run`
